# ☕ Aprende Java desde 0

¡Hola! Bienvenido/a  a este repositorio.👋
## 📌 Sobre este proyecto
Como alumna de 1º de DAM (Desarrollo de Aplicaciones Multiplataforma)**, he creado este repositorio con un doble objetivo:
* **Para mí:** Servir como guía y diario de aprendizaje para mantener todo mi código organizado a lo largo del curso.
* **Para ti:** Ayudar a cualquier persona que esté empezando con Java y no sepa por dónde arrancar, ofreciendo ejercicios prácticos y explicados paso a paso.

## 🛠️ Estructura del repositorio
A medida que avance en las clases, iré subiendo ejercicios organizados por bloques:
* `01-Introduccion`: Sintaxis básica, variables y tipos de datos.
* `02-EstructurasDeControl`: Condicionales (`if`/`else`, `switch`) y bucles (`for`, `while`).
* `03-POO`: Programación Orientada a Objetos (clases, objetos, herencia, etc.).
* `04-EjerciciosPracticos`: Pequeños proyectos y problemas resueltos.
